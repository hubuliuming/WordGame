# 末世玄幻战斗模式 AI 图片生成标准模板

模板版本：1.0。

## 使用范围与事实边界

- 本文件记录用户已确认的战斗图片生成模板，适用于战斗概念图、角色与敌人设定、武器道具图、攻击特效概念图和战斗 HUD 概念图。
- 战斗模式参考用户提出的“类似饥荒”方向；荒野生存主题的外部参考见[《饥荒》官方介绍](https://www.klei.com/games/dont-starve)。统一美术方向为末世玄幻、荒野求生、风格化手绘质感和清晰战斗轮廓。
- 项目现有 3D 实时近战原型包含移动、攻击前摇、命中、后摇及敌人反击。当前功能与调用链以[战斗](Modules/Combat.md)、[玩家](Modules/Player.md)和[运行入口](Modules/Runtime.md)为准，本文件不重复定义玩法规则。
- 本文件的角色名称、场景名称、服装、武器外观、敌人造型、特效及 HUD 均属于出图内容。与真实项目对象的映射未确认时保持 `UNKNOWN`，不能据图片或提示词认定功能已经接入。
- 正式镜头、分辨率、角色比例、资源映射和生产资源规格仍为 `UNKNOWN`。下文画幅为已确认模板中的出图参考，示例镜头仅用于对应概念图。

## 一、统一美术方向

| 维度 | 统一要求 |
|---|---|
| 末世表达 | 风化建筑、断裂道路、残破装备、稀疏植被、文明衰败 |
| 玄幻表达 | 古老符纹、残损法器、宗门遗迹、异化生物、局部微弱灵光 |
| 造型 | 大形体明确，细节集中在辨识位置，破损具有结构逻辑 |
| 色彩 | 灰褐、炭黑、骨白作为基础；暗朱红、黯青作为少量强调色 |
| 材质 | 粗布、锈铁、裂石、枯木、旧皮革、兽骨 |
| 战斗表现 | 主体朝向、攻击姿态、双方距离和可移动地面容易辨认 |
| 光影 | 环境低饱和，角色与敌人保持明暗区分，发光范围克制 |

每张图选择两至三个核心风格元素，避免同时堆满废墟、符咒、触手、浓雾和发光效果。

## 三、通用提示词模板

按固定顺序填写，批量生成时保持“统一风格”和“固定外观特征”一致。方括号中的内容由本次图片需求替换。

```text
请生成一张用于【图片用途】的游戏美术图片。

统一风格：
末世玄幻与荒野求生氛围，风格化手绘质感，
形体简洁，轮廓清楚，低饱和灰褐、炭黑和骨白，
以【强调色】作局部点缀。
材质体现风化、磨损和修补，灵光克制。

主体：
【名称、数量、体型、服饰或身体结构、装备】。
固定辨识特征为【三个关键特征】。

动作与状态：
【本张图片只表达的一个主要动作或状态】。
明确表现【朝向、重心、攻击方向或双方距离】。

场景与镜头：
【环境】。
使用【镜头角度与投影要求】，主体朝向【方向】，
构图为【主体位置、画面占比、留白位置】。

战斗可读性：
主体与背景保持轮廓和明暗区分，
脚下地面与主要活动空间清楚可见，
装饰、烟雾和特效不遮挡关键动作。

输出：
【比例】，【尺寸】，【背景要求】，
【单张独立图片或明确指定的设定图布局】。

保持：
【本轮必须保持的特征】。

允许变化：
【本轮唯一允许变化的内容】。

避免：
【与本次图片用途对应的禁止内容】。
```

## 四、分类模板补充要求

| 图片类型 | 提示词必须补充 | 画幅参考 | 检查重点 |
|---|---|---|---|
| 战斗场景概念图 | 玩家与敌人位置、当前战斗阶段、移动空间、镜头 | 16:9 | 距离、朝向和地面是否清楚 |
| 角色设定图 | 体型比例、服装层次、装备位置、固定辨识特征 | 3:4 | 全身完整，同一角色外观一致 |
| 敌人设定图 | 身体结构、攻击部位、普通姿态或前摇姿态 | 1:1 或 3:4 | 轮廓与攻击姿态容易辨认 |
| 武器与道具图 | 单件对象、材质、破损位置、展示角度 | 1:1 | 小尺寸下仍能识别 |
| 攻击特效概念图 | 起点、方向、作用范围、形状与透明背景要求 | 1:1 | 特效形状清楚，主体不被遮挡 |
| 战斗 HUD 概念图 | 信息区域、生命与体力位置、留白和装饰密度 | 16:9 | 信息优先级与战斗区域清楚 |

画幅参考不构成正式生产默认值。HUD、武器外观和特效属于视觉设计范围，具体功能接入依据另外确认的方案执行。

## 五、可直接使用的示例

以下角色和场景为独立美术概念，对应项目对象均为 `UNKNOWN`。每例为完整内容提示词；生成前仍须按第二节填写图片编号、实际输出尺寸等记录字段，并在所用生成工具中设置对应参数。

### 示例 A：战斗场景概念图

```text
生成一张末世玄幻生存游戏的战斗场景概念图，16:9。

场景为衰败宗门外围的荒地，地面有裂石、枯草和少量断碑。
采用风格化手绘质感，灰褐与炭黑为主色，
骨白用于轮廓区分，少量黯青灵光点缀。

使用斜俯视三分之四镜头，人物全身和脚下地面清楚可见。
一名幸存修士位于画面中下部，穿修补灰衣，
右肩覆旧皮护肩，腰间挂破损符袋，持锈蚀短刀。
这三个外观特征保持明确。

一只畸变荒兽位于人物前方，身体低伏，
前肢蓄力，表现即将发动近身攻击的姿态。
人物保持警戒，双方尚未接触。
周围保留清楚的移动与退让空间。

背景细节集中在画面边缘，
人物、荒兽与地面保持明暗和轮廓区分。
输出单张完整场景图片。

避免文字、水印、密集粒子、遮挡脚部的浓雾、
过度发光、拥挤构图和裁切主体。
```

### 示例 B：敌人攻击前摇设定图

```text
生成一张“裂甲荒兽”的攻击前摇设定图，1:1，纯浅灰背景。

末世玄幻，风格化手绘质感。
四足兽体，宽肩低重心，背部覆盖断裂骨甲，
左侧獠牙折断，额头有一道暗朱红裂纹。
骨甲、断牙和额头裂纹为固定辨识特征。

主体面向画面左前方，全身完整，
头部压低，前肢蓄力，后肢支撑，
通过姿态明确表现即将攻击的状态。

灰黑皮肤与骨白甲片形成区别，
裂纹只局部微亮，不覆盖身体结构。
仅生成一个主体，四周保留空白。

避免新增肢体、改变骨甲排列、裁切脚部、
复杂背景、文字、水印和遮挡主体的特效。
```

### 示例 C：武器图标

```text
生成一张“残纹短刀”的游戏道具图标，1:1，透明背景。

末世玄幻，风格化手绘质感。
单把短刀，刀身有浅锈与两处小缺口，
握柄缠旧灰布，护手刻残损黯青符纹。

武器沿左下至右上方向排列，
轮廓完整，主体占画面约四分之三，
强调刀刃、护手与握柄的区分，
缩小后仍能清楚识别。

仅生成武器本体，不生成图标边框。

避免文字、水印、手部、场景背景、
大范围发光、过密纹饰和裁切刀尖。
```

## 六、批量生成与验收标准

### 批量生成记录

- 同一角色固定体型、服装结构、装备位置和三个辨识特征；每轮只改变指定动作或状态。
- 同一组图片固定镜头、朝向、画幅、光源方向和配色。
- 每张图片保存最终提示词、生成工具、实际参数、版本和生成日期。

### 文档验收

- 必填字段、通用模板、六类图片补充要求和三个完整示例齐全。
- 统一风格描述与各示例一致，参考规格和正式项目规格的边界明确。
- 独立美术概念及未确认映射保持明确，未将新视觉概念写成已接入功能。

### 图片验收与交付边界

- 场景图检查战斗距离与活动空间；角色图检查结构与一致性；图标检查缩小后的辨识度。
- 透明背景应由生成工具实际设置，交付时检查 Alpha；格纹底图不能视为透明。
- AI 图片作为概念或美术参考交付。3D 模型、动画、无缝贴图等用途需要对应的后续制作与验证。
- 图片视觉检查遵守 [AGENTS.md](../AGENTS.md)：仅在用户明确要求查看指定图片，或已确认方案明确授权指定范围的图片验证时执行。
- 文档验收只覆盖模板内容完整性，不构成图片视觉验收或 GamePlayer PlayMode 验收结论。
